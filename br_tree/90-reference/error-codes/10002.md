**Error:** 10002

**Description:** Input during sleep forces on exit processing

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BRETRAPSLEEPKEY`

**Source:** BR 5 `wberrdefs.h`, `BRETRAPSLEEPKEY`.
