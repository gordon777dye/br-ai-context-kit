**Error:** 10011

**Description:** All odbc file numbers are in use

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BREODBCALLFILESUSED`

**Source:** BR 5 `wberrdefs.h`, `BREODBCALLFILESUSED`.
