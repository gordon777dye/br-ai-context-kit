**Error:** 6234

**Description:** Printing windlg printer not found

**Earlier documentation:** this page gave "Pderr parsefailure", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** The [devices] section of the WIN.INI file did not contain an entry for the requested printer
