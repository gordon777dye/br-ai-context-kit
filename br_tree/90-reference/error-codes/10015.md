**Error:** 10015

**Description:** Wbserver error wbserver.dat corrupt

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `WBS_CORRUPT_FILE`

**Source:** BR 5 `wberrdefs.h`, `WBS_CORRUPT_FILE`.
