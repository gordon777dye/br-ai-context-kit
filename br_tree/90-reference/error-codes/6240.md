**Error:** 6240

**Description:** Failed opening printer DC

**Earlier documentation:** this page gave "Pderr generalcodes", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** Named or selected printer info was found but no printer device context could be created
