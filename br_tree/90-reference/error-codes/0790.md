**Error:** 0790

**Description:** HTTPS .key file is not a PEM private key

**Name:** `BREHTTPSKEYFORMAT`

**Details:** It holds something else, such as a certificate, or a key that is damaged.

**SYSERR$:** The path and OpenSSL's reason.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> PEM, beside the `.crt` and with the same base name.

**Fix:** Put the PEM private key in the file.

Available as of BR! `5.02`.
