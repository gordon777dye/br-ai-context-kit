**Error:** 6226

**Description:** Printing windlg default different

**Earlier documentation:** this page gave "Pderr createfailure", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** This error happens when an application stores the DEVNAMES structure and the user changes the default printer by using Control Panel. (DEVNAMES changed)
