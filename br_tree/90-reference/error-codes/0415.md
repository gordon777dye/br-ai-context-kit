**Error:** 0415

**Description:** Some error that has err message   OR   bad FILE$ information type specifier

**BR 5 message:** bad FILE$ information type specifier or generic MSG error with string error message

**Details:** See also the `Msg` `internal function`.

**BR 5.01:** `MSG("menu", <path$>)` with a path that names no item of the menu BR shows on its main window raises 0415; BR's log lists the paths the menu has.
