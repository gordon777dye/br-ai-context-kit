**Error:** 0711

**Description:** Unable to restore

**BR 5 message:** unable restore relative or keyed open output

**Details:** Cannot restore relative or keyed file using OPEN OUTPUT. A RESTORE statement was issued for a key-indexed or relative file that is open for output. Correct the error causing program statement.
