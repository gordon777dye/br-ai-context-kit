**Error:** 0750

**Description:** Could not start the HTTP server

**Name:** `BREHTTPSERVERUNAVAILABLE`

**Source:** BR 5 `wberrdefs.h`, `BREHTTPSERVERUNAVAILABLE`.

**Setup documentation:** [HTTP_SERVER.md §3.2 Steps](../../60-integration/web/HTTP_SERVER.md#tls-steps)

> **Check the log** given by `LOG=`.

**Fix:** This code is what remains when no other fits, such as lack of memory. `SYSERR$` and the logs give the reason.
