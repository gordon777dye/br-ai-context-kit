**Error:** 7810

**Description:** Invalid index file name

**BR 5 message:** attempt to SORT a file that is not an internal file

**Details:** Specification of an invalid file type for the input file in a SORT command. The input file must be an internal record file. Use PRESORT to correct the procedure or correct the program that created the sort control file.
