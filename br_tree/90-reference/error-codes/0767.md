**Error:** 0767

**Description:** CHUNK= is valid only with HTTP=SERVER

**Name:** `BREHTTPCHUNKUSE`

**Details:** `CHUNK=` was given on a file that is not `HTTP=SERVER`.

**Setup documentation:** [HTTP_SERVER.md §2.1 Statements](../../60-integration/web/HTTP_SERVER.md#interface)

> Given on a file that is not `HTTP=SERVER`: error **0767**.

**Fix:** Remove `CHUNK=`, or add `HTTP=SERVER`.

Available as of BR! `5.02`.
