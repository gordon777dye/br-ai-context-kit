**Error:** 6233

**Description:** Printing windlg parse failure

**Earlier documentation:** this page gave "Pderr Nodevices", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** The print dialog function failed to parse the strings in the [devices] section of the WIN.INI file
