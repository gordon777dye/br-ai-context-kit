**Error:** 0787

**Description:** HTTPS .crt file holds a private key - are .crt and .key swapped?

**Name:** `BREHTTPSCRTISKEY`

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> PEM. The **server certificate first, then its intermediate certificate(s)**, in one file - what certificate authorities call the *full chain* (certbot's `fullchain.pem`).

**Fix:** Put the certificate in `.crt` and the key in `.key`.

Available as of BR! `5.02`.
