**Error:** 10016

**Description:** Wbserver bad locking version - option 33

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `WBS_BAD_VERSION`

**Source:** BR 5 `wberrdefs.h`, `WBS_BAD_VERSION`.
