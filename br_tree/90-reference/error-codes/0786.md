**Error:** 0786

**Description:** HTTPS certificate file is binary (DER or PFX) - convert it to PEM

**Name:** `BREHTTPSCRTBINARY`

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §3.2 Steps](../../60-integration/web/HTTP_SERVER.md#tls-steps)

> A certificate delivered as a `.pfx` / `.p12` converts with OpenSSL:

**Fix:** Convert it with the `openssl` commands in that step.

Available as of BR! `5.02`.
