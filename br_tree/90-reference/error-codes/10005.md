**Error:** 10005

**Description:** Could not find the given ENV variable

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BREENVNOTFOUND`

**Source:** BR 5 `wberrdefs.h`, `BREENVNOTFOUND`.
