**Error:** 9400

**Description:** DEPRECATED ERROR in BR 5: Output file corrupted

**Details:** Incorrect information written during a SAVE; program may be corrupted on disk. LIST  >temp.brs to save the current program in memory so that it may be reloaded from source later
