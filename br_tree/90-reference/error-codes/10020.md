**Error:** 10020

**Description:** Wbserver problem re-opening file shared

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `WBS_ERR_SHARE`

**Source:** BR 5 `wberrdefs.h`, `WBS_ERR_SHARE`.
