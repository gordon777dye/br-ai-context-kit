**Error:** 0770

**Description:** Unknown word on CONFIG HTTP or HTTPS - quote a value containing spaces

**Name:** `BREHTTPCFGKEYWORD`

**Details:** A word on a `CONFIG HTTP` or `HTTPS` line is not a keyword: a misspelling, or the rest of a value with a space in it. Raised by `CONFIG`. A line in `brconfig.sys` is raised by the first `HTTP=SERVER` OPEN.

**SYSERR$:** The word. After `PHRASE=` it says only that, so that a passphrase is not repeated.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> A word the directive does not know is error 0770. Put quotes round a value containing a space, or the rest of the value counts as an unknown word.

**Fix:** Correct the keyword, or quote the value: `URL_BASE="C:\Program Files\site"`.

Available as of BR! `5.02`.
