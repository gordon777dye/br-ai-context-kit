**Error:** 4170

**Description:** A line the assistant sent tried to set `AI_TURN_OK`

**Details:** The consent flag for an `AI` turn is the person's to give. A line the assistant sent that tries to set `AI_TURN_OK` is refused with this error, and the attempt is logged. See [4169](4169.md).

**Name:** `BREAITURNFLAGNOTSET`

**Source:** BR 5.0 `wberrdefs.h`, `BREAITURNFLAGNOTSET`: "the assistant's own commands may not set AI_TURN_OK - only the program or procedure bridging the turn may".
