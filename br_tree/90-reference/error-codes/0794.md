**Error:** 0794

**Description:** HTTPS .crt must list the server certificate first, then intermediates

**Name:** `BREHTTPSCHAINORDER`

**Details:** The key fits a later certificate in the file, so the file is in the wrong order.

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §3.2 Steps](../../60-integration/web/HTTP_SERVER.md#tls-steps)

> Concatenate the server certificate and its intermediate(s), in that order, into `<basename>.crt`

**Fix:** Rebuild the file with the server certificate first.

Available as of BR! `5.02`.
