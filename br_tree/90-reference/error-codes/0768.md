**Error:** 0768

**Description:** This BR license does not include HTTP

**Name:** `BREHTTPNOLICENSE`

**Details:** The BR is built with HTTP support, but its licence allows no HTTP clients.

**SYSERR$:** The licence count.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> Without HTTP support the OPEN fails with 9990; without an HTTP licence, 0768.

**Fix:** Obtain a licence that includes HTTP. `STATUS LICENSE` lists the HTTP licence.

Available as of BR! `5.02`.
