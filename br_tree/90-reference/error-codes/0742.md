**Error:** 0742

**Description:** Request not valid because this is not an HTTP server
Available as of BR! `4.30`.

**Setup documentation:** [HTTP_SERVER.md §2.3 FILE$ inquiries](../../60-integration/web/HTTP_SERVER.md#file-inquiries)

> On a channel that is not `HTTP=SERVER` these raise **742**.

**Fix:** Use these keywords only on an `HTTP=SERVER` channel.
