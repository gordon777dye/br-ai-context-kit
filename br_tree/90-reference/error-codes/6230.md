**Error:** 6230

**Description:** Printing windlg error loading driver

**Earlier documentation:** this page gave "Pderr Initfailure", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** The printer dialog function failed to load the device driver for the specified printer
