**Error:** 0779

**Description:** HTTP LOG= names a folder, not a file

**Name:** `BREHTTPLOGISDIR`

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Server log file, as a **BR name** (resolved through `DRIVE`). Its folder must already exist, and the name must be a file, not a folder.

**Fix:** Add a file name.

Available as of BR! `5.02`.
