**Error:** 0752

**Description:** HTTP port is in use by another program or BR session

**Name:** `BREHTTPPORTUNAVAILABLE`

**Source:** BR 5 `wberrdefs.h`, `BREHTTPPORTUNAVAILABLE`.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> The HTTPS port and the HTTP port, because both listen (§1). A port in use gives 752.

**Fix:** Free the port or choose another. Behind a proxy, give a range with one port per BR process. `SYSERR$` names the port.
