**Error:** 6225

**Description:** Printing windlg create IC failure

**Earlier documentation:** this page gave "Cderr structsize", a Windows common-dialog constant name that the wiki lists one position off from the BR 5 error table. The Details below are unchanged.

**Details:** The PrintDlg function failed when it attempted to create an information context.
