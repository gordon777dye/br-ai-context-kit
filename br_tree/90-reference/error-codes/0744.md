**Error:** 0744

**Description:** Request not valid because this is not an HTTP client
Available as of BR! `4.30`.

**Setup documentation:** [HTTP_SERVER.md §2.3 FILE$ inquiries](../../60-integration/web/HTTP_SERVER.md#file-inquiries)

> Client channels only. On a server channel: error **744**.

**Fix:** Use `HTTPINFO` only on an `HTTP=CLIENT` channel.
