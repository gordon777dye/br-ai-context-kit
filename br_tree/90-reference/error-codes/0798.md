**Error:** 0798

**Description:** A request body was over 64 MB and was refused

**Name:** `BREHTTPBODYTOOLARGE`

**Details:** **Never raised**, so that a client cannot stop a server. The client gets 413, the server log records it, and `FILE$(n,"HTTP-REFUSED")` counts it.

**Setup documentation:** [HTTP_SERVER.md §2.4 Reading a request](../../60-integration/web/HTTP_SERVER.md#request-body)

> A body over **64 MB** is refused with **413** before the program sees it

**Fix:** Nothing to fix in the setup. It describes a client's request.

Available as of BR! `5.02`.
