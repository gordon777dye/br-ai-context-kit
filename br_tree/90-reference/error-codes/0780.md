**Error:** 0780

**Description:** HTTP URL_BASE= folder does not exist

**Name:** `BREHTTPURLBASE`

**Details:** The name was tried as an operating-system path and then as a BR path through `DRIVE`.

**SYSERR$:** The path as tried.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> It must exist and be a folder: a wrong `URL_BASE=` fails the OPEN.

**Fix:** Create the folder or correct the path. Use `URL_BASE=NONE` if BR serves no files.

Available as of BR! `5.02`.
