**Error:** 606

**Description:** Invalid element in `Open` `statement`

**Details:** The Open statement includes an invalid element in the KPS= or KLN= string. Some possibilities:
- The record length, key position or key length for an Open statement is either missing or invalid.
- `Open Linked` statement attempted to use first 8 bytes of record as key field (releases `3.60` and higher). #Add or correct the `RecL`=, KPS= and/or KLN= parameters.
- don't do that.
