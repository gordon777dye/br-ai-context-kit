**Error:** 0777

**Description:** CONFIG HTTP or HTTPS value is too long or has an unmatched quote

**Name:** `BREHTTPCFGVALUE`

**Details:** Raised as for 0770.

**SYSERR$:** The keyword, never the value.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Put quotes round a value containing a space

**Fix:** Shorten the value, or close the quote.

Available as of BR! `5.02`.
