**Error:** 9990

**Description:** This version was made without HTTP support

**Details:** Add HTTP support
Available as of BR! `4.20`.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> Without HTTP support the OPEN fails with 9990; without an HTTP licence, 0768.

**Fix:** Use a BR built with HTTP support.
