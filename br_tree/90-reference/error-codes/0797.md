**Error:** 0797

**Description:** HTTP BIND= address is not on this machine

**Name:** `BREHTTPBINDADDRESS`

**SYSERR$:** The address and port.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Listen on this one address of this machine (IPv4, or IPv6 without brackets), or a host name that resolves to one, instead of on all of them.

**Fix:** Give an address of this machine, or remove `BIND=`.

Available as of BR! `5.02`.
