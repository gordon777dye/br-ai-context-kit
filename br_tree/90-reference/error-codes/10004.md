**Error:** 10004

**Description:** Failed accessing registry values

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BREREGISTRYACCESS`

**Source:** BR 5 `wberrdefs.h`, `BREREGISTRYACCESS`.
