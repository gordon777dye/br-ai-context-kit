**Error:** 10014

**Description:** Wsid is already in use in another session

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `WBS_IDINUSE`

**Source:** BR 5 `wberrdefs.h`, `WBS_IDINUSE`.
