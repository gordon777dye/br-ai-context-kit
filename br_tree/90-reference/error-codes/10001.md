**Error:** 10001

**Description:** Trigger function key error trap

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BREFUNCTIONKEYTRAP`

**Source:** BR 5 `wberrdefs.h`, `BREFUNCTIONKEYTRAP`.
