**Error:** 0792

**Description:** HTTPS private key passphrase is wrong

**Name:** `BREHTTPSBADPHRASE`

**Details:** `web_server.br` keeps it in `<CERT base>.phrase`; delete that file for it to ask again.

**SYSERR$:** The path and OpenSSL's reason, never the passphrase.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> `PHRASE=`, or the `OPTION 66` value when there is no `PHRASE=`.

**Fix:** Give the right passphrase.

Available as of BR! `5.02`.
