**Error:** 10009

**Description:** Trap an input slash during primop processing

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BRETRAPINPUTSLASH`

**Source:** BR 5 `wberrdefs.h`, `BRETRAPINPUTSLASH`.
