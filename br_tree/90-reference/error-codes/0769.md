**Error:** 0769

**Description:** An uploaded file could not be stored

**Name:** `BREHTTPUPLOADFAILED`

**Details:** **Never raised.** `FILE$(n,"UPLOAD-ERROR")` returns `769,<reason>` for the current request. The request still reaches the program, without its `&uploadfile=`.

**Setup documentation:** [HTTP_SERVER.md §2.6 File uploads](../../60-integration/web/HTTP_SERVER.md#uploads)

> The file goes in `tmp`, under BR's working directory, which is created if missing.

**Fix:** Check that BR can write to `tmp`, and that the client's file name is valid on this system.

Available as of BR! `5.02`.
