**Error:** 0774

**Description:** THREADS= must be 1 to 1000

**Name:** `BREHTTPCFGTHREADS`

**Details:** Raised as for 0770.

**SYSERR$:** The value.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> The most worker threads the server starts, 1 to 1000; default **50**.

**Fix:** Give a value in range, or leave out `THREADS=`.

Available as of BR! `5.02`.
