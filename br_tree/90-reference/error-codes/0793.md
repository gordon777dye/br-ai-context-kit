**Error:** 0793

**Description:** HTTPS private key does not belong to the certificate

**Name:** `BREHTTPSKEYMISMATCH`

**Details:** Commonly a renewed certificate with the old key, or the reverse. In a renewal the server logs this code and keeps the previous pair.

**SYSERR$:** The two paths.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> BR checks that it belongs to the certificate.

**Fix:** Install the key issued with this certificate.

Available as of BR! `5.02`.
