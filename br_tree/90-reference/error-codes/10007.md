**Error:** 10007

**Description:** There is no config attribute with the give name

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BRENOCONFIGATTR`

**Source:** BR 5 `wberrdefs.h`, `BRENOCONFIGATTR`.
