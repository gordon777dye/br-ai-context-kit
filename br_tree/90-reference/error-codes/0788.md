**Error:** 0788

**Description:** HTTPS private key file not found - `<base>.key` must sit beside `<base>.crt`

**Name:** `BREHTTPSKEYMISSING`

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> PEM, beside the `.crt` and with the same base name.

**Fix:** Put the key there, under the certificate's base name.

Available as of BR! `5.02`.
