**Error:** 0791

**Description:** HTTPS private key is encrypted - give PHRASE= or OPTION 66

**Name:** `BREHTTPSNOPHRASE`

**SYSERR$:** The path and OpenSSL's reason.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> `PHRASE=`, or the `OPTION 66` value when there is no `PHRASE=`.

**Fix:** Give the passphrase, quoted if it contains spaces.

Available as of BR! `5.02`.
