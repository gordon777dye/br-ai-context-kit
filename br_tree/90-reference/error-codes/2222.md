**Error:** 2222

**Description:** More than one of -W -R -C flags were specified on a `Shell` call

**BR 5 message:** mutually exclusive flags given for system command

**Details:** More than one of -W -R -C flags were specified on a Shell call Remove the incorrect flag(s).
