**Error:** 4165

**Description:** brrestrict.sys does not permit this file

**Details:** The site's `brrestrict.sys`, beside the BR executable, lists the folders and files BR may work with, and this file is not among them - either the list **excludes** it explicitly or it simply does not permit it, and the log says which. The list binds every BR session, restricted or not, and governs reading, creating, changing, renaming, deleting and listing alike. An exclusion is absolute: a file the session created itself is no exception. In an AI turn the list is checked before the assistant's permission question, so a file it refuses is not asked about.

**Raised by:** `file_os.cpp`
