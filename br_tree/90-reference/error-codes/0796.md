**Error:** 0796

**Description:** The system denied this BR the HTTP port

**Name:** `BREHTTPPORTDENIED`

**Details:** The port is not in use, and the operating system refuses it: a port below 1024 on Linux, or a port Windows has reserved.

**SYSERR$:** The port and whether it is HTTP or HTTPS.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> The HTTPS port and the HTTP port, because both listen (§1).

**Fix:** Use another port, or run BR with the right to use this one.

Available as of BR! `5.02`.
