**Error:** 0783

**Description:** HTTPS certificate file not found - CERT= is the name without .crt

**Name:** `BREHTTPSCRTMISSING`

**Details:** BR adds `.crt` to `CERT=`, so `CERT=server.crt` looks for `server.crt.crt`. The name is tried as an operating-system path and then as a BR path.

**SYSERR$:** The path as tried.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Base name of the certificate pair, without an extension: `<basename>.crt` and `<basename>.key` (§3).

**Fix:** Correct `CERT=`, or put the file there.

Available as of BR! `5.02`.
