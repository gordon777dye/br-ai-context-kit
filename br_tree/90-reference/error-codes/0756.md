**Error:** 0756

**Description:** Failed to open the http server log file

**Name:** `BREHTTPSERVERLOGFILEOPENFAILURE`

**Source:** BR 5 `wberrdefs.h`, `BREHTTPSERVERLOGFILEOPENFAILURE`.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Server log file, as a **BR name** (resolved through `DRIVE`). Its folder must already exist, and the name must be a file, not a folder.

**Fix:** Check that the account running BR can write the file. A missing folder is 0778, and a folder named as the file is 0779. `SYSERR$` shows the path.
