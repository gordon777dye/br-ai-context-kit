**Error:** 0703

**Description:** Illegal access by REC=

**Details:** - Attempt to access a sequential file with a REC= clause.
- Attempt to access an internal file with a POS= clause. # Open the file `RELATIVE` or remove the REC= clause.
- Open the file `EXTERNAL` or remove the POS= clause.
