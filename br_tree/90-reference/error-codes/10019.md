**Error:** 10019

**Description:** Wbserver failed to truncate existing file

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `WBS_NO_TRUNC_SVR`

**Source:** BR 5 `wberrdefs.h`, `WBS_NO_TRUNC_SVR`.
