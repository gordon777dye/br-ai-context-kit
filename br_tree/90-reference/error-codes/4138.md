**Error:** 4138

**Description:** Can't rename from one file system to another, or between `client` and `server`

**Details:** `RENAME` never copies. Its *to* must be on the same drive, share or mounted file
system as its *from*, and both on the client (`@:`) or both on the server. Otherwise the rename
is refused and both names are left as they were; use `COPY` and then `FREE` to move a file there.
Available as of BR! `4.30` for client and server; BR 5.0 added the file-system case and the
wording. Before 5.0, Windows copied a file renamed to another drive and deleted the original, and
Unix refused it with 4320. See [RENAME](../../70-commands/file-directory/spec.md#rename-filesystem).
