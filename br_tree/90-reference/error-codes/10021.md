**Error:** 10021

**Description:** Combo auto complete search not found

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BRECOMBONOTFOUND`

**Source:** BR 5 `wberrdefs.h`, `BRECOMBONOTFOUND`.
