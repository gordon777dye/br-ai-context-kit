**Error:** 4172

**Description:** This `OPTION` may be set only in the configuration file, never with a `CONFIG` command

**Details:** Raised by `CONFIG OPTION 83` at run time, whoever issues it ([`OPTION 83`](../../00-configuration/config-directives/OPTION_(Config).md#option-table)). Set `OPTION 83` in `brconfig.sys` instead. A restricted session is refused it outright.

**Name:** not named in the release notes

**Source:** BR 5.0 `wberrdefs.h`, `BREOPTIONFILEONLY`: "this OPTION may be set only in the configuration file, never with a CONFIG command".
