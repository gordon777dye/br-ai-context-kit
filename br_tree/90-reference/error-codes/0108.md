**Error:** 0108

**Description:** `Maximum String Length` (`32,767`) Exceeded

**BR 5 message:** system string function result is too large

**Details:** A string functions yields a result that exceeds the maximum length of a string (32,767 bytes), such as RPT$("=", 36000). Rearrange your logic so that you may manage multiple pieces of the large string.
