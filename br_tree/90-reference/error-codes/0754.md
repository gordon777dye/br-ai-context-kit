**Error:** 0754

**Description:** Failed to process path information for the http server log file

**Name:** `BREHTTPSERVERBADLOGFILEPATH`

**Source:** BR 5 `wberrdefs.h`, `BREHTTPSERVERBADLOGFILEPATH`.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> Server log file, as a **BR name** (resolved through `DRIVE`).

**Fix:** Correct the `LOG=` name. `SYSERR$` shows it.
