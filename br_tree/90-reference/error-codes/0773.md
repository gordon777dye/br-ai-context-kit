**Error:** 0773

**Description:** CONFIG HTTP or HTTPS keyword has no value

**Name:** `BREHTTPCFGNOVALUE`

**Details:** A keyword ends the line, or the next keyword follows it directly. Raised as for 0770.

**SYSERR$:** The keyword.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> `CERT=` with nothing after it, or followed by another keyword, is error 0773.

**Fix:** Give the value, or remove the keyword.

Available as of BR! `5.02`.
