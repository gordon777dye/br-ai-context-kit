**Error:** 4169

**Description:** `AI` was used while a program or procedure was active and `ENV$("AI_TURN_OK")` was not `"Y"`

**Details:** A turn cannot break into a running program: an AI turn can `LOAD`, and BR never lets an interrupted program be replaced (`SAVE`, `REPLACE`, `RENUM` and `RUN` refuse with 2108). Set `ENV$("AI_TURN_OK")` to `"Y"` (lower case `"y"` counts, `"YES"` does not) before the `AI` command, or end what is running. Raised before the assistant hears of it. Nothing running needs no flag, and `AI NEW` and a proc whose last line is the `AI` line need none.

**Name:** `BREAITURNNOTPERMITTED`

**Source:** BR 5.0 `wberrdefs.h`, `BREAITURNNOTPERMITTED`: "a program or procedure is active: set ENV$("AI_TURN_OK") to "Y" before an AI command, or end what is running".
