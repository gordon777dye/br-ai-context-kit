**Error:** 4299

**Description:** cannot copy or rename file to itself



**BR 5.0:** A folder copied or moved into itself (`COPY -R` with a *to* inside the folder being copied, or `MOVE src src\sub`) is refused with 4299, because the copy would be among what it copies.
