**Error:** 0764

**Description:** An HTTP file must be opened DISPLAY

**Name:** `BREHTTPNOTDISPLAY`

**Details:** An `HTTP=` file was opened `INTERNAL` or `EXTERNAL`.

**Setup documentation:** [HTTP_SERVER.md §2.1 Statements](../../60-integration/web/HTTP_SERVER.md#interface)

> The file must be `DISPLAY`, opened `OUTIN`: it reads requests and writes their responses.

**Fix:** Open it `DISPLAY`.

Available as of BR! `5.02`.
