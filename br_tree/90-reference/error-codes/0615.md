**Error:** 0615

**Description:** Illegal `open` for `display` file

**BR 5 message:** DISPLAY files that are not windows or async communications may not be opened OUTIN

**Details:** Invalid access attempted for display file. Only `communication files` can be accessed with `OutIn`. Change access keyword.
