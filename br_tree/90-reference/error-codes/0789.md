**Error:** 0789

**Description:** HTTPS private key file cannot be read

**Name:** `BREHTTPSKEYREAD`

**Details:** The name exists but will not open: it is a folder, or BR has no access to it.

**SYSERR$:** The path.

**Setup documentation:** [HTTP_SERVER.md §3.1 Prerequisites](../../60-integration/web/HTTP_SERVER.md#tls)

> A private key file, `<basename>.key`

**Fix:** Replace it with the file, or give the account running BR read access.

Available as of BR! `5.02`.
