**Error:** 0776

**Description:** PROXY= must be numeric IP addresses separated by commas

**Name:** `BREHTTPCFGPROXY`

**Details:** `PROXY=` is compared as text with the address a request came from, so a host name could never match. Raised as for 0770.

**SYSERR$:** The value.

**Setup documentation:** [HTTP_SERVER.md §1 Configuration directives](../../60-integration/web/HTTP_SERVER.md#setup)

> The IP address of a local reverse proxy such as NGINX, or several separated by commas, written as numbers (`127.0.0.1`).

**Fix:** Write the proxy's address as numbers.

Available as of BR! `5.02`.
