**Error:** 10003

**Description:** Input during fields forces on exit processing

**Details:** An internal trap. BR uses this number inside its own error handling and it should never reach a program.

**Name:** `BRETRAPFIELDSONEXIT`

**Source:** BR 5 `wberrdefs.h`, `BRETRAPFIELDSONEXIT`.
