**Error:** 0799

**Description:** A client was refused: all HTTP licenses are in use

**Name:** `BREHTTPNOSEATS`

**Details:** **Never raised.** The client gets 503, the server log records it, and `FILE$(n,"HTTP-REFUSED")` counts it first, for licence management.

**Setup documentation:** [HTTP_SERVER.md §2.7 Other behaviour](../../60-integration/web/HTTP_SERVER.md#lifecycle)

> Licences are counted per client IP address seen within 30 minutes.

**Fix:** Add HTTP licences, or wait for addresses to expire. `STATUS LICENSE` lists the HTTP licence.

Available as of BR! `5.02`.
