**Error:** 4149

**Description:** File Open. Different version of BR running with locking

**Details:** File being opened is also open in another version of BR: BR 5.01 and a release
before 5.01 never have the same file open together, whatever its share-spec. The one that opens the
file second gets this error; on Windows with `OPTION 33 31` or `32`, an earlier release gets
[4175](4175.md) instead. Close the file in the other version first.
